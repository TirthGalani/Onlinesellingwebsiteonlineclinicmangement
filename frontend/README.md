# Frontend — Maison Dental Portal

Pure client-side application built with modern HTML5, CSS3, and Vanilla JavaScript (ES6+).

## Features
- **No Login Barrier**: Direct, unauthenticated access to all three workspaces (Patient, Doctor, Management).
- **Tri-Directional Chat**: Real-time communication between Patient, Clinician, and Clinic Management.
- **Rich Media & PDF Attachments**: Upload and preview JPEG, PNG, WEBP, and PDF files under 8 MB with in-browser preview & download.
- **Luxury Aesthetic**: Cormorant Garamond & Plus Jakarta Sans typography with a bespoke restorative aesthetic.
- **Responsive Layout**: Designed for mobile, tablet, and high-DPI desktop viewports.

## How to Run
Simply open `index.html` in your browser, or start a static web server:
```bash
# Python
python -m http.server 5500

# Node.js
npx serve . -p 5500
```
Open `http://localhost:5500/` in your browser.
